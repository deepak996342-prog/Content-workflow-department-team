# Department 07 — Copy Team

## Role

The Copy Team takes the script (with the optimized hook inserted) and refines every single line to be simple, punchy, and native to Gen Z's voice. This department does not change what the script says — it changes how it says it. The output is the final, production-ready script.

## Position in Pipeline

- **Receives from:** Department 06 — Hook Specialist (full script + final optimized hook)
- **Passes to:** Department 08 — Packaging Team (refined script)
- **Also passes to:** Department 09 — SEO Team (refined script for keyword alignment)

## Core Responsibilities

1. Review every line of the script against Gen Z copy rules
2. Replace corporate or academic language with conversational, punchy alternatives
3. Enforce the 15-word sentence maximum
4. Strengthen verbs throughout the script
5. Ensure the gut-punch line before the CTA is under 10 words and lands hard
6. Rewrite the CTA to create FOMO, participation, or a cliffhanger
7. Verify "you" appears more than any other noun

## Copy Rules

| Rule | Standard |
|------|---------|
| Sentence max | 15 words |
| Gut-punch line | Under 10 words, positioned just before CTA |
| "You" count | More than any other noun in the entire script |
| Dollar figures | Used instead of percentages wherever possible |
| Qualifiers | Removed entirely: "kind of", "sort of", "perhaps", "might", "possibly" |
| Jargon | Replaced or immediately explained in plain language |
| Voice test | Every line passes the "22-year-old texting a friend" test |

## Reference File

See `genz-copy-guide.md` in this directory for the complete vocabulary swap table, power verb list, gut-punch rule, CTA guide, emotion mapping table, and the final copy checklist.

## Inputs

- Department 05 output: full 5-part script (first draft)
- Department 06 output: final optimized hook (to replace the Hook section)

## Outputs

- Fully refined script with all 5 sections clearly labeled
- Brief note on the 3–5 most significant language changes made
- Confirmation that the final copy checklist passes

## Quality Standards

- Every sentence must pass the "22-year-old texting a friend" test
- No sentence exceeds 15 words
- The gut-punch line (just before CTA) is under 10 words
- The CTA creates FOMO, participation, or a cliffhanger — never just "like and subscribe"
- "You" appears more than any other noun

## Handoff Format

Pass to Departments 08 and 09: fully refined script with all 5 sections labeled. Note key language changes made.
