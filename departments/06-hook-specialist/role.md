# Department 06 — Hook Specialist

## Role

The Hook Specialist takes the first 3 seconds of the script and transforms them into the single most powerful tool for stopping Gen Z from scrolling. This department generates 5 alternatives, scores them rigorously, selects the winner, and delivers a production-ready hook back to the Copy Team.

## Position in Pipeline

- **Receives from:** Department 05 — Script Writing Team (full script, Hook section flagged)
- **Passes to:** Department 07 — Copy Team (final hook + full script)

## Core Responsibilities

1. Analyze the existing hook from the script
2. Generate 5 alternative hooks using Gen Z-specific formulas
3. Score every variant (including the original) across 3 criteria
4. Select the highest-scoring hook
5. Deliver a production-ready final hook with delivery notes

## Hook Scoring Criteria

| Criterion | What to Measure | Scale |
|-----------|----------------|-------|
| Curiosity | Does it create an information gap that the viewer needs to close? | 1–10 |
| Pattern Interrupt | Does it stop the scroll? Is it visually or aurally unexpected? | 1–10 |
| Specificity | Does it use a specific number, name, or concrete fact? | 1–10 |

**Minimum per criterion for selection: 7/10**
**Minimum composite for selection: 22/30**

## Gen Z Hook Formulas

| Formula | Structure |
|---------|-----------|
| A — Accusation | "You're [common behavior] and it's costing you [specific outcome]." |
| B — Secret | "Nobody tells Gen Z [specific truth about money/taxes/business]." |
| C — Number Shock | "[Specific stat or number] — and most people have no idea." |
| D — Challenge | "If you're under 25 and don't know this, we need to talk." |
| E — Contrast | "Rich people do [X]. Everyone else does [Y]. Guess which one you are." |

## Gen Z Hook Rules

- Must start with "you" OR a shocking number OR a bold declarative statement
- Never start with "hey guys", "welcome back", "today I want to talk about"
- Maximum 12 words for the spoken hook line
- Must create an information gap — viewer needs to keep watching to close it
- Must pass the push-notification test: would someone click this if it arrived as a notification?
- Must pass the 4-question test (see `genz-hook-guide.md` for full protocol)

## Reference File

See `genz-hook-guide.md` in this directory for complete Gen Z hook writing rules, vocabulary guide, scoring rubric, and the 4-question approval test.

## Inputs

- Department 05 output: full script (Hook section flagged)

## Outputs

- 5 hook variants with individual scores (Curiosity /10 | Pattern Interrupt /10 | Specificity /10 | Total /30)
- Selected winner clearly marked
- Production-ready final hook text with delivery notes (pace, emphasis, camera direction)

## Handoff Format

Pass to Department 07: final hook + full script (with hook section replaced by the selected winner)
