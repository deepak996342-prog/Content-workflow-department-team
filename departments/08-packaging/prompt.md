## Deliver All 5 Elements

---

### ELEMENT 1 — Thumbnail Concept

Describe the thumbnail in detail. Include:

```
THUMBNAIL CONCEPT
─────────────────
Layout: [Describe the visual layout — split, centered, full-bleed, etc.]
Creator: [What is the creator doing? Expression, pose, gesture]
Text Overlay: [Exact text on thumbnail — max 5 words, high contrast]
Color Palette: [2–3 colors. Name them. Explain the psychology.]
Background: [Solid color / gradient / location / graphic]
Font Style: [Bold / condensed / serif / etc.]
Bottom Strip (optional): [Short provocative line at the bottom — e.g., "Your CA won't tell you this"]

WHY THIS THUMBNAIL WORKS:
[1 sentence explaining why a Gen Z viewer stops scrolling on this]
```

**Thumbnail Rules:**
- Must communicate the video's value with zero audio
- Text must be readable at mobile thumbnail size (under 150px wide)
- High contrast between text and background — no light text on light background
- One clear focal point — not cluttered

---

### ELEMENT 2 — Caption / Title

Write the caption opening (the first 125 characters that appear before "more"):

```
CAPTION / TITLE
───────────────
Platform: Instagram Reels
Text (max 125 chars): [Caption text — must end before "more" cuts it off]

Platform: TikTok
Text (max 125 chars): [Adapted version for TikTok tone]

Platform: YouTube Shorts
Text (max 60 chars): [Title — YouTube Shorts shows a shorter title]
```

**Caption Rules:**
- Must create curiosity or urgency before the cutoff
- Must not give away the payoff — the viewer must watch to get it
- Can use 1–2 emojis if they add meaning (not decoration)

### ELEMENT 3 — Opening Visual (Frame 1)

Describe exactly what the viewer sees in the very first frame of the video:

```
OPENING VISUAL — FRAME 1
─────────────────────────
What's on screen: [Describe the first visual — text card, creator close-up, graphic, etc.]
Creator position: [If creator is visible — framing, angle, expression]
Text on screen: [If text appears in Frame 1 — exact wording]
Energy match: [How does this visual match the hook's energy?]
```

**Frame 1 Rules:**
- Must match hook energy exactly — a shocking stat hook needs a shocking visual
- Must work without audio — 85% of Gen Z preview with sound off
- No logos, no intros, no channel names in Frame 1
